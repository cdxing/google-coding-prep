## Daily 90-Minute Session

```
10 min  Blind rewrite of yesterday's template
35 min  One timed problem
10 min  Stuck protocol / get hint / continue
15 min  Test + debug
10 min  One follow-up (change a condition)
 5 min  English explanation out loud
 5 min  3-line pattern card
```

## Stuck Protocol

When you don't recognize the pattern within 5 minutes:

1. Restate known conditions and goal
2. Say what you've ruled out and why
3. Give brute force solution
4. Find repeated/expensive work in brute force
5. Use data structure to eliminate that work

> "I don't see the optimal approach yet, so I'll start with a correct baseline
> and inspect where the repeated work happens."

## Communication Scripts

```
Clarify:    "Let me make sure I understand the problem correctly..."
Direction:  "My initial thought is to use ___ because ___."
Pre-code:   "Before I code, let me walk through the approach."
Testing:    "Let me trace the code with a small example."
Follow-up:  "If we change ___, the key difference is..."
```

## Timing Checkpoints (not hard deadlines)

```
0-10 min   Problem definition + baseline + optimization direction
15 min     Should be coding
20 min     If not coding, simplify approach or ask for hint
30-35 min  Code complete + testing
40 min     Clean wrap-up
Remaining  Follow-up
```
